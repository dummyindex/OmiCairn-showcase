# Screenshots of OmiCairn v1 (code name Stoneflow)

Screenshots and clips of OmiCairn's first version, code name Stoneflow, a workflow-based web
platform for omics analysis (fully deprecated and retired), used on `/platform/`
(15 gallery images + 1 hero image + 3 clips).

Sources: the first version's user guide, and an updated set of OmiCairn-branded captures
(5 screenshots, 3 clips) supplied by the authors. Images are WebP (full size,
max 2000 px wide) plus a `-thumb.webp` (880 px wide) for the gallery grid. Clips are H.264 MP4
(1024 px wide, 25 fps, no audio, metadata stripped) with a WebP poster frame.
